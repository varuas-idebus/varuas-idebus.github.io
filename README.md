# Saurav Subedi — Animated Portfolio

## Open the design

1. Extract the entire ZIP folder.
2. Open `index.html` in a modern browser, such as Chrome, Edge, Firefox, or Safari.
3. Use Home, Projects, About me, and Let's talk to explore the views.
4. Open a project to explore its Overview, Architecture, and My contribution.

No installation, build step, server, or API key is required.

## Files to edit

- `index.html`: page structure and most visible text.
- `styles.css`: responsive layouts, colors, fonts, and animations.
- `script.js`: navigation, project data, project details, motion, and contact preview.

All views are part of one frontend document; navigation changes the visible view locally. You can later split these into routes or components in your chosen framework.

## Included motion

Headline reveals, page entrance transitions, floating elements, orbital animation, a moving technology strip, rotating role text, pointer-based project-card tilt, hover effects, and animated project architecture highlights.

The footer includes a pause/resume control. Reduced-motion system preferences are respected. If motion is reduced in your operating system or browser, continuous animations may be disabled.

## Appearance and dependencies

The design follows your system's light/dark appearance. Google Fonts requires an internet connection; fallback fonts work offline. The interface and animations use plain HTML, CSS, and JavaScript, with no framework dependency.

## Contact form

This is a frontend design prototype. The form validates fields and displays a preview completion state. It does not send, save, or upload messages. Add a backend or email service when implementing real contact functionality.
